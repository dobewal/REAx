# Disclaimer — read before using REAX

## Educational and authorized use only

REAX is built for **education, learning, and authorized security research**.
It shows you how Android apps are put together — nothing more.

## What you may use it for

- Learning how APKs, manifests, permissions, and DEX code work
- Auditing **your own** apps or apps you have **explicit written permission** to test
- Classroom teaching, coursework, and published security research conducted responsibly
- Improving the security of software you own or are hired to assess

## What you may NOT use it for

- Analyzing someone else's app to steal code, bypass licensing, remove protections,
  or clone features without permission
- Finding vulnerabilities to exploit rather than to report and fix
- Any activity that breaks the law in your country, or violates an app's terms of service

## If you find a vulnerability

Report it to the app's developer or vendor first, privately, and give them a
fair chance to fix it before any public disclosure.
